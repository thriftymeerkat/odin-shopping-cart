# The Odin Project (Full Stack Javascript) - Shopping Cart

Designing and building a store page / shopping cart where uses can add and remove items to a shopping cart that renders on the cart page complete with test files.

Full project specs can be found [here](https://www.theodinproject.com/lessons/node-path-react-new-shopping-cart).

Fake store items sourced via the [Fake Store API](https://fakestoreapi.com/).

Background image for homepage sourced via [Unsplash](https://unsplash.com/photos/bicycle-parked-outside-lamp-shop-F6-U5fGAOik).
